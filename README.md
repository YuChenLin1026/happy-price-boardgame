# 快樂有價：天庭賭局（財神 vs 喜神）

4–5 人、15 歲以上、約 20 分鐘的純卡牌桌遊。財神和喜神在天庭打賭：凡人到底要錢，還是要快樂？
每位玩家扮演學生、醫生、上班族、房東或軍人，在娛樂、投資和天庭拍賣會之間做選擇。
遊戲結束時，金錢加上開心值換算（1 個開心值 ＝ 1,000）就是總分。
